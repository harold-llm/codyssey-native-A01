# 나만의 프롬프트 관리

GenAI 미션에서 작성한 프롬프트를 한 곳에 모아 관리하는 Python 콘솔 프로그램입니다.
프롬프트를 카테고리별로 분류하고, 키워드로 검색하며, 자주 사용하는 항목은
즐겨찾기로 관리할 수 있습니다.

## 실행 방법

```bash
# Python 3.10 이상 필요
python main.py
```

실행 후 출력되는 메뉴에서 번호를 입력해 기능을 선택합니다. `0`을 입력하면 프로그램이 종료됩니다.

## 기능 목록

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트를 등록합니다 (빈 입력 시 재입력 요청) |
| 2 | 프롬프트 목록 | 저장된 모든 프롬프트를 번호, 카테고리, 즐겨찾기(⭐)와 함께 표시합니다 |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리의 프롬프트만 표시합니다 |
| 4 | 프롬프트 검색 | 키워드로 제목 또는 내용이 일치하는 프롬프트를 검색합니다 |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목·카테고리·즐겨찾기·내용 전체를 표시합니다 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가/해제합니다 |
| 7 | 즐겨찾기 목록 | 즐겨찾기된 프롬프트만 모아서 표시합니다 |
| 0 | 종료 | 프로그램을 종료합니다 |

> 프롬프트와 즐겨찾기 상태는 프로그램 실행 중에만 유지되고, 종료 시 초기화됩니다.

## 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

추가할 때 미리 정의된 목록에서 고를 수도 있고, 직접 입력한 새 카테고리를 만들 수도 있습니다.

## 기본 프롬프트

프로그램 시작 시 이전 미션에서 작성한 프롬프트 4개(블로그 글 작성 도우미, 제품 썸네일 생성,
IT 컨설턴트 페르소나, 뉴스 요약)가 미리 등록되어 있습니다.

## 데이터 구조

프롬프트는 **리스트 + 딕셔너리**로 저장됩니다. 각 프롬프트에는
`title`(제목), `content`(내용), `category`(카테고리), `favorite`(즐겨찾기 여부)가 있습니다.

```python
PROMPTS = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "당신은 10년 경력의 전문 블로거입니다...",
        "category": "텍스트 생성",
        "favorite": True,
    },
]
```

## 요구 사항

- Python 3.10 이상
- 외부 라이브러리 불필요 (기본 문법만 사용)
